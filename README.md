# 期末复习 Skill · Exam Revision

**把一学期的 Word / PDF 课件，整理成看得懂、查得到、能练习的 Markdown 复习包。**

适合在 Codex 等支持本地 Skill 的工具中使用。它不是独立聊天网站：宿主模型负责理解和讲解，脚本负责来源提取、进度保存与基础检查。

## 先看效果

- [详细复习示例](examples/demo-output/02-详细复习.md)：概念、通俗例子、正式步骤、例题和易错点。
- [精简复习示例](examples/demo-output/02-精简复习.md)：核心结论、关键条件和最小例题。
- [自测卷](examples/demo-output/练习卷/A-基础.md) · [独立解析](examples/demo-output/答案/A-解析.md)
- [原创 Word / PDF 输入](examples/demo-inputs/)：可直接用来试跑，不含私人课件。

## 使用：说一句话就开始

把资料放进课程项目的 `课件` 文件夹，或按宿主支持的方式上传，然后说：

> 使用 $exam-revision，把课件整理成详细版期末复习包，复杂概念用容易理解的例子讲清楚，再出3套练习卷，答案单独放。输出到“复习包”。

其他常用说法：
- **精简版：**“只保留核心知识点、公式、算法和代表例题，但不要省略使用条件。”
- **两版都要：**“详细版用于学习，精简版用于考前回顾。”
- **中断后继续：**“继续复习包，先查看已有进度，从未完成的章节接着做，不要覆盖我改过的笔记。”

不用先填写一堆设置。未指定时默认详细版、中文、3套自编练习卷；考试范围、题型和时长未知时会明确标记，不冒充押题或真实考试要求。

## 这次优化了什么

### 更好读
复杂概念先给一句话直觉和生活/数值例子，再回到正式定义、公式条件与逐步例题。类比会说明边界，避免“讲得简单却讲错了”。精简版也保留理解必需的条件。

### 长课程可以接着做
每完成一章就保存输出和检查点。下次新对话读取本地进度，从未完成项继续。长材料按章分文件，主讲义提供导航，避免把所有内容挤成一篇巨文。

进度追踪器会检查原课件和已登记输出是否变化。发现你改过的笔记、缺失文件或新增课件，会报告差异，保留原内容。只有旧笔记改动时，可以保留它们并继续新章节，但冲突会持续标记；课件变化或文件丢失时会停止，避免把不同版本混在一起。它**不是自动后台任务**，需要你在宿主工具里继续发起执行；也不能从代码层阻止模型绕过流程直接写文件，因此 Skill 明确要求遵守检查结果。

### 更容易核对
知识点保留文件/页码或 Word 文本块定位；题目与答案分开；有覆盖清单和解析失败提醒。结构检查支持请求的模式、卷数、引用ID和本地链接；有检查点时默认读取保存的模式和卷数，也可以显式指定。

## 会生成什么

| 文件 | 用途 |
|---|---|
| 00-开始阅读.md | 范围、限制和推荐顺序 |
| 01-知识地图.md | 章节和知识点导航 |
| 02-详细复习.md / 02-精简复习.md | 对应模式的讲义，长课程链接到章节文件 |
| 03-考前速查.md | 核心公式、概念、步骤 |
| 04-覆盖与待核对.md | 已覆盖、精简省略、资料不清楚的地方 |
| 练习卷/ 与 答案/ | 默认3套自编练习及独立解析 |
| _sources/ | 来源文本与定位清单 |

内部检查点单独保存，不需要学生手工编辑。需要技术用法时看 [续做说明](references/resume.md)。

## 输入与费用

- 支持 `.docx` 和文字型 `.pdf`。旧 `.doc` 请先另存为 `.docx`，不是改后缀。
- 扫描 PDF、手写、复杂公式和图表需要额外视觉/OCR检查；脚本不提供 OCR。
- PDF按物理页引用；Word按正文块定位，不伪造会随软件变化的页码。
- Python提取依赖：`python -m pip install -r requirements.txt`。安装依赖前遵循宿主权限流程；脚本本身不调用网络API。
- 模型生成仍遵循 Codex/WorkBuddy 的收费与数据处理规则。使用本地脚本不等于课件不会发送给云端模型。

## 质量边界

脚本检查“文件在不在、是否被改过、引用ID是否存在”等可确定事项。模型负责解释、例题、练习题和答案；这些仍需核对。**没有零幻觉、必考、全覆盖或提分保证。**

不会自动发布课件、共享复习包或修改原资料。公开仓库只包含原创微型示例；老师的课件、往年卷和私人笔记应保存在仓库外。
