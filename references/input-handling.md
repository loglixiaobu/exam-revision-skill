# 输入处理

## 支持边界
- `.pptx`：按演示文稿中的幻灯片顺序读取文本和表格，讲者备注单独保留。隐藏页仍记录并提醒，不视为默认考试范围。文本来自文件中的对象顺序，可能不同于实际视觉阅读顺序；图片、公式、图表、SmartArt、媒体和动画不能仅靠提取文字完整理解，需视觉核对。
- `.ppt`：旧二进制格式不直接解析。请在 PowerPoint/WPS/已有可信 LibreOffice 中另存为 `.pptx`，或导出PDF到新目录，保留原件。改后缀无效；PDF可能不包含讲者备注、隐藏页和动画各步，转换后需核对。
- `.pdf`：pypdf 提取文字并保留物理页码。单页提取失败时保留该页定位和警告，继续处理其他页。页面实际绘制图片时会逐页提醒，图片不一定是扫描件，也可能是图表或装饰；不能用“文字很多”判断页面完整。PDF 书面印刷页码可另外记录，不能与物理页混淆。加密、损坏、扫描件可能无法解析。
- `.docx`：读取正文段落、表格（含单元格内嵌套文本）与内容控件，保留顺序、制表符和换行；对图像、OMML公式、文本框和批注/页眉页脚等附属内容警告。仅含公式或图像的正文块也保留定位，但文本是明确的未转写占位，不是公式或图片内容。自动编号、合并/嵌套表格会提醒核对。Word 排版页码随字体与软件改变，因此使用章节/块编号。
- `.doc`：不直接解析二进制旧格式。请另存 `.docx`，或在已安装 LibreOffice 时转换到独立目录，再把转换后的文件作为输入；检查转换前后是否丢失公式/图片。未经用户确认，不声称旧 DOC 已处理。
- 其他扩展名记录为未支持；不执行文件中的宏，不打开外部链接，不递归跟随符号链接。

## 定位标记
PDF `[S001:p0001]` 对应物理第1页；DOCX `[S002:b0003]` 对应正文第3个有文本或视觉占位的块。生成的 sources.md 保存标记与文本；manifest.json 保存文件路径、SHA256、状态、单元计数和警告。PPTX `[S003:s0002]` 是演示文稿顺序中的第2张幻灯片，`[S003:n0002]` 是该页讲者备注，不是第二份备注文件。备注未出现时不生成备注引用。引用必须原样使用已有标记。

这些标记可核对，但不自动提供原文件深链接。用户可按原文件名/物理页或文本块标题查找。需要图片时另存本地图片并用相对路径插入 Markdown，保留出处。

## 失败恢复
未提取文字的页不应被当成无内容；检查是否扫描件。宿主能视觉读取时逐页识别并以原来源 ID 记录校对后的内容；无该能力时报告需要 OCR，不虚构完整复习包。OCR 工具不是此包依赖；使用前遵守宿主权限与数据分享要求。

公式提取文本即使看似正常也可能错序。尤其分数、上下标、矩阵、证明图必须视觉核对。若未核对，写入限制报告。目录中包含练习/真题时给材料单独分类，避免将答案当普通课件内容。

## PPTX 特别说明

讲者备注属于独立来源，引用时标明“讲者备注”，不能伪装成幻灯片可见文字。发现备注与正文冲突时同时保留出处并列出疑点，不默默选一个版本。隐藏页仍保留定位与内容，是否纳入复习范围需要说明。

PPTX 不展开母版、版式、背景、批注或外部链接中的内容；缓存字段不等于实时更新结果。图表与SmartArt会保留未解析提醒，不能声称已读出图表数值。任何“公式未转写”“图形未解析”占位都只是定位，不是学习材料正文。

为避免异常文件耗尽资源，PPTX 文件大小、ZIP展开总量及累计XML读取分别上限100MiB，单个XML上限8MiB，累计文本上限1000万字符；还限制成员数、页数、嵌套和压缩比。重复引用的页与备注同样计入累计限额。触发保护时拆分原课件再处理，不通过改后缀或忽略警告绕过。不会访问外部关系、执行宏或播放媒体。
