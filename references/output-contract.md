# Markdown 复习包规范

目录结构（单模式保留一种；双模式同时生成两种）：
```
00-开始阅读.md
01-知识地图.md
02-详细复习.md  /  02-精简复习.md
03-考前速查.md
04-覆盖与待核对.md
练习卷/A-基础.md
练习卷/B-综合.md
练习卷/C-迁移.md
答案/A-解析.md
答案/B-解析.md
答案/C-解析.md
_sources/manifest.json
_sources/sources.md
```

长课程可增加 `章节/详细/01-章节名.md` 与 `章节/精简/01-章节名.md`，主 `02-…复习.md` 保留导航和全局阅读建议，不重复所有正文。每个章节文件保留来源引用；进度文件由 session.py 管理，不手工伪造完成状态。

`00-开始阅读.md` 说明输入、模式、考试信息、练习性质、推荐使用顺序与未解决限制。不要把原始提取文本复制成讲义；不能只产出模板。

## 知识点规范
知识点编号 K001...，来源如 `[S001:p0002]`。同一来源支持一组紧邻内容时可统一引用，但关键公式、例题和重要结论均须有明确来源。
- 阅读体验：复杂概念先给一句直觉及通俗例子，再给严谨定义和条件；例子注明原题/改编/补充，类比说明边界。短段落、清晰小节、逐步例题优先于密集术语堆叠。
- 详细版：定义、必要解释、公式条件与符号、算法输入输出/步骤/复杂度（只在资料可支撑时）、主要例题及过程、易错点。
- 精简版：核心结论、公式条件、算法骨架和至少覆盖各主要题型的代表例题；不设机械字数比例。
- 补充讲解注明“补充解释”；推导注明起始来源与推导过程；不得为新增结论贴不相关页码。
- 原课件包含答案错误时不静默修改，列出疑点、自己的核算与需要确认之处。

## 覆盖清单
每项记录：知识点ID、章节、主题、来源、材料类型、模式纳入状态、去向和原因。初始知识地图标“计划/待处理”，不能预填“已覆盖”；完成讲义后以真实文件与复核结果更新最终覆盖清单。状态用“待处理 / 已覆盖 / 精简省略 / 待视觉核对 / 信息不足 / 范围外”。
详细版逐章统计实质知识点覆盖，不对无法解析的文件宣称覆盖率；若报告比例，说明分母仅为已识别知识点，不能当成整门课程覆盖率。

## 练习卷
每套明确“自编练习卷，非真实考题预测”。开头给题型、分值合计与建议时长，答案写在独立文件。
- A：基本概念与标准步骤；B：跨知识点应用；C：边界、易混点及合理迁移。
- 题型跟随课程；未知考试题型时标为练习设计建议，不机械混入选择题。
- 每题给唯一题号。题目不包含答案或评分关键词提示；知识点及出处映射放入解析，避免泄题。
- 答案包括推理、评分点、常见错误与来源；必要时接受等价答案。主观题给合理评分框架而非唯一措辞。

## 最终检查
必须核对每套分值合计、题答编号一一对应、公式符号一致、引用支持内容、Markdown 本地链接有效。删去残留模板和伪造出处。若受上下文或工具限制，准确交付已完成部分并列出剩余，不将未完成标为完成。
