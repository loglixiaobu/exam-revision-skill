# 让复习包真正读得懂

## 详细版：先建立直觉，再进入正式内容
对抽象、易混或学生常卡住的概念，按以下顺序组织；简单事实无需套全套模板：
1. **一句话理解**：不用新术语解释新术语。
2. **直观例子**：生活类比、最小数值例子、一步步变化的状态，选最贴合课程的一种。
3. **回到正式定义**：明确符号、条件、适用范围；类比不是证明。
4. **走一遍例题**：写清“为什么做这一步”，而不只有结果。
5. **容易错在哪**：给反例或边界，指出直觉何时失效。
6. **自检一句**：一个可以独立回答的小问题，答案放折叠说明或该章末尾，不强迫互动后才能继续。

每章开头用2–3行说明“本章解决什么问题”和先修知识；按概念分成短小节。长文档用章节文件与目录链接，不写成一堵墙。不要频繁重复“掌握”“很重要”等空话。

## 精简版：压缩文字，不压掉理解必需的条件
每个核心点保留：一句直觉 + 正式结论/公式条件 + 最小例题 + 一个易错提醒。熟悉的简单点可以合并。可链接到详细版对应章节，但不能让精简版必须依赖详细版才能看懂。

## 示例：二分查找
**一句话理解：**在排好序的候选中，每次比较中间值，就能排除不可能的一半。

**直观例子（补充解释）：**在按字母排序的词典里查一个词，翻到中间发现目标应在后面，就不必再查前半本。这个比喻依赖“已排序”；乱序笔记本不能这样找。

**回到算法：**课件使用闭区间 `[low, high]`，候选包括两端。检查 `a[mid]` 后，中点不等于目标时应将它排除，所以边界更新为 `mid+1` 或 `mid-1`。来源应引用课程实际页码，不要给此模板虚构来源。

**最小例题：**`[1,3,5,7,9]` 查7：中间值5太小，剩 `[7,9]`；下一次命中7。区分返回的下标3与元素值7。

## 示例：O(log n) 不等于“运行 log n 秒”
用候选规模的变化解释：1024→512→256→…→1，约10次折半就缩到1个候选。规模翻倍，只多一次折半，说明增长慢。这是规模直觉，**不是该代码的精确比较次数公式**。
然后回到课件定义：大O描述增长阶，不是秒数。实现、机器和常数都会影响实际耗时。不要由“对数增长”推出小输入必然比所有线性方法快。

## 来源与例子的边界
- 原课件例题注明来源；新类比或改编题标“补充解释/改编”，仍指出所解释的知识点来源。
- 类比须说清对应关系与至少一个重要边界；不能把抽象概念错误简化。
- 文史课程可用短情境、概念对照和论证步骤；不强制算法或数值例子。
- 如果原资料不足以支撑补充结论，缩回能确认的解释并标记待核对，不靠故事填补缺失定理。

## 核对练习区分度
三套卷的区分体现在解题任务而不只是题号和数字：基础卷检验标准步骤，综合卷需要选择方法或结合多个知识点，迁移卷检验条件改变后的边界。每套题目蓝图应准确对应实际题目；不要用“另有应用题”等含糊描述替代核对。
