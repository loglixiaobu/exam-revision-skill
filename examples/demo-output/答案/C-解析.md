# C 答案
## C1
n=0，low=0、high=-1（2分）；0<=-1为假，不进入循环（1分），不读取元素（1分），返回未找到（1分）。常见错误是先访问mid才检查条件。K005；基于[S002:b0004]改编。
## C2
low=0、high=4，mid=2（1分），a[2]=2，返回下标2（1分）。首个下标是0，本次不满足要求（1分）。普通二分命中即返回某个位置，不能保证首个匹配（2分）。常见错误是把返回元素值2和索引2混淆，即使本题数字相同也要说明是索引。K003、K006；基于[S001:p0002] [S002:b0004] [S002:b0006]改编。

## C3
初始low=high=0（1分），错误条件0<0为假，循环不执行（1分）。报告未找到错误，因为7存在（1分）。闭区间两端相等仍包含一个候选，必须允许这一轮检查（2分）。常见错误是把区间长度为1当成空区间。K003；基于[S001:p0002]的补充推演题。
