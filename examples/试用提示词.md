# 详细版
使用 exam-revision。读取 ./课件 中的 Word/PDF，生成详细版 Markdown 复习包，覆盖大部分知识点、公式、算法和例题，提供讲解；另生成三套自编练习卷和独立答案。考试范围未提供，不能宣称预测真题。输出到新的 ./复习包-详细 目录。

# 精简版
使用 exam-revision。读取 ./课件，生成精简版 Markdown 复习包，包含核心知识点、关键公式条件、算法步骤、代表例题及易错点，并生成三套练习卷和独立答案。对省略内容给出清单，不能悄悄忽略无法读取的页。输出到 ./复习包-精简。

# 两种都要
使用 exam-revision，读取 ./课件，基于同一份知识清单生成详细和精简两种讲义，共用三套练习卷和独立答案，输出到 ./复习包-双模式。老师明确考试只覆盖第1至4章；其余材料只在有必要解释前置概念时使用并标记。
